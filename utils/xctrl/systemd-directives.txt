# The default systemd directives that the [systemd] section of magaox.conf or an app's .conf may set.
#
# make install in utils/xctrl installs this file as /etc/magaox/systemd-directives.txt, always overwriting it, and
# copies it to /etc/magaox/systemd-directives.local.txt if it does not exist.  xctrl reads the .local copy, or
# falls back to standard systemd-directives.txt. 
#
# xctrl sync registers apps with systemd and includes any of the overrides in this allowlist if they are present 
# in the <appname>.conf or magaox.conf files. The allowlist should only ever be root:root permissions so that 
# a malicious systemd directive cannot be included in an app setting.   
# 
# A [systemd] key may start with a lower-case letter: watchdogSec is treated like WatchdogSec.
#
# Dangerous or powerful directives should not be included, for example those that name files or paths systemd opens
# or mounts as root (StandardOutput=file:..., StandardInput, StandardError, TTYPath, RootDirectory, RootImage, 
# BindPaths, ReadWritePaths, LoadCredential, StateDirectory, LogsDirectory, PIDFile), that run commands (Exec...),
# or that change who the app runs as or what it may do (User, Group, capabilities): any of those could allow an 
# app to become root and do something malicious.
