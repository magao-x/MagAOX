# systemd directives that the [systemd] section of magaox.conf or an app's .conf may set on this host.
#
# THIS IS THE FILE TO EDIT, with sudo, to add or remove directives: xctrl reads only this file,
# /etc/magaox/systemd-directives.local.txt.  make install in utils/xctrl created it from the defaults,
# /etc/magaox/systemd-directives.txt, and never changes it again, while it overwrites the defaults on every install;
# compare the two after an update to pick up new defaults.  One directive per line, as systemd spells it; # starts
# a comment.  A [systemd] key may start with a lower-case letter: watchdogSec sets WatchdogSec.
#
# xctrl sync writes these into the apps' systemd units, as root, for any user who can edit the proclist.  Never add
# directives that name files or paths systemd opens or mounts as root (StandardOutput=file:..., StandardInput,
# StandardError, TTYPath, RootDirectory, RootImage, BindPaths, ReadWritePaths, LoadCredential, StateDirectory,
# LogsDirectory, PIDFile), that run commands (Exec...), or that change who the app runs as or what it may do (User,
# Group, capabilities): any of those would let a proclist editor become root.  xctrl refuses the worst of them
# (Exec..., User, Group, capabilities, host actions such as a reboot) even if they are listed here.
